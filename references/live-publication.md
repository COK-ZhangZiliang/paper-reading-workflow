# Zotero、Notion 与在线发布

用户请求完整论文精读或完整笔记时，默认读取本参考并执行 Zotero 到对应 Notion 数据库条目的发布流程；用户明确要求从 Zotero 取文、发布或修改 Notion 笔记时也读取。若用户明确要求仅回答、只生成草稿、本地保存或不要写入 Notion，则不写入；单项技术追问只有在用户要求修订笔记时才使用本流程。

## 识别来源与目标

起草或修改前，同时确认操作两端。

- 先确认对应 Notion 数据库、祖先路径、属性结构和候选条目。数据库只有一个合理候选时才继续；存在多个合理数据库时必须先确认，不能猜测。
- 以论文的准确标题和版本元数据搜索条目。唯一匹配时更新该条目；没有匹配时，在创建前立即重新搜索一次，仍未命中才在对应数据库中新建条目。不得在数据库外创建独立页面，也不得因搜索差异创建重复条目。
- 更新既有条目时，除非用户要求修改，否则保留页面标题、图标、父级或数据库归属、标签、摘要及其他无关属性。新建条目时，使用已核实的论文标题，并只填写数据库必填字段和一手来源能够确认的元数据，不猜测标签或摘要。
- 在 Zotero 中按标题或条目 key 搜索，检查父条目的子附件，选择真正的 `Full Text PDF`。不能因为 Snapshot 排在最前面就把它当作论文正文。
- 标题重复或未命中时，检查附件与版本元数据。若个人库中确实没有论文，只能在权限允许时改用官方公开版本，并在交付说明中报告来源与版本，不为此新增笔记模块。
- `403`、本地 API 未启用或沙箱返回 `Operation not permitted` 都属于访问失败，不能据此判断论文不存在。

如果元数据消歧后仍有两个合理的匹配条目，必须在在线写入前停止并确认。没有匹配条目且对应数据库唯一时，按上述规则新建；对应数据库本身不明确时，交付草稿并报告阻断点，不能把页面建到猜测的位置。

## 用在线基线保护写入

修改前立即重新获取页面，并把该响应作为本次编辑基线。

- 只有目标正文为空、用户明确要求整体替换，或现有正文整体就是要被新稿替代时，才替换全文。
- 其他情况应找出唯一的小节边界，只修改满足请求所需的最小区间。若并发保护不再匹配，先重新获取页面；不能为了强行成功而扩大替换范围。
- 正文更新不得顺带覆盖数据库属性或相邻在线内容。
- 写入进入队列后，轮询到终态。异步任务成功只表示请求已处理，不代表页面渲染正确。

发布完整笔记时，在线正文也必须遵守用户指定的内容边界。采用默认结构时，只写入 `TL;DR`、`Background`、`Motivation`、`Method`、`Experiments` 和 `Drawbacks`；无论论文标题、作者、版本、状态、原文链接或来源路径是否已存在于页面属性中，都不在正文新增“论文信息”表、目录或参考资料模块，除非用户明确要求。

默认不向 Notion 新增图片块。把从相关图表获得的观察直接融入它所支持的现有正文段落，并沿用该段落的普通格式；除非用户明确要求逐图分析，不新增“图表解读”标题、逐图 callout、卡片、清单或过程标签。图号可以在句中用于定位证据，但不能代替具体说明。用户要求插入图片时，记录原始页和图注、按上下文放置每张图片，并保留预期的唯一图片清单，以便最终检查重复项和空占位符。

## 回读并验收

每次全文写入或局部修订后，都要重新获取渲染页面。按本次请求检查：

- 页面、祖先路径与数据库条目正确；
- 新建场景下只产生一个条目，标题、必填字段和可核实元数据正确；
- 更新既有条目时，除用户授权修改的字段外，标题、图标、标签、摘要及其他属性保持不变；
- 正文非空，用户要求的部分及顺序正确，且没有自行增加其他模块；采用默认结构时只有 `TL;DR` 和五个指定章节，没有论文信息表或目录；
- 公式、表格、链接、来源和关键数值仅在内容确实需要时出现，并位于相应章节中；不为凑齐格式元素而新增内容；
- 未要求插图时，相关图表证据已自然融入对应正文，没有新增独立图表解读模块或图片块；要求插图时，图片块、图注和唯一性符合预期且没有空占位符；
- 除章节标题外，正文的段落、列表、表格和 callout 没有任何 Markdown、HTML 或 Notion 加粗，且行内代码和数学标记没有损坏；
- 局部编辑后的相邻小节与刚才取得的在线基线一致。

只修复已经证明存在的最小缺陷，然后再次回读。只有通过这一步，才能报告“已发布且回读验证通过”。否则应准确使用“草稿已完成”“目标已找到”“写入排队中”“写入失败”或“发布未验证”等状态。

## 常见恢复决策

- 长 Markdown 格式损坏：先写入临时文件，或改用连接器支持的结构化内容接口，再检查实际渲染结果。
- 在线小节已变化：重新获取、重新定位当前边界；仅当用户要改的内容仍然缺失时才重试。
- 缺少连接器或权限：交付可直接使用的独立草稿，并说明在线写入或回读仍受阻。
- 目标页元数据过时：只有一手来源能证实且用户授权维护内容时才修正，否则仅提示差异。
